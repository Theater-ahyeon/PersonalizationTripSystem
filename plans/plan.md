# 个性化旅游系统开发计划（纯 C++ 版）

## 1. 计划说明

本计划用于指导纯 C++ 版本的后续开发。自 2026 年 4 月 12 日起，仓库不再保留 Java 或其他并行实现，项目只围绕 C++ 一条主线推进。

## 2. 总体目标

最终形成一个基于 C++ 的个性化旅游系统，满足以下目标：

- 启动时从 JSON 和二进制文件加载数据到内存
- 运行期通过 CLI 调用五个核心模块
- 退出时将必要变更写回文件
- 核心功能全部建立在手写数据结构和算法之上
- 具备完整文档、测试结果和可答辩的演示链路

## 6. 风险与对策

### 风险一：功能过多导致主线失焦

对策：

- 所有开发优先围绕 P0
- P1 和 P2 不影响主交付

### 风险二：文件读写和编码问题

对策：

- 统一使用 UTF-8
- 先保守支持当前样例格式
- 为文件读写补独立测试

### 风险三：算法实现与演示脱节

对策：

- 每新增一个模块，都先保证 CLI 可演示
- 文档和代码同步更新

## 7. 当前结论

当前项目只保留 C++ 版本，后续所有开发、文档、测试和答辩材料都以 `cpp/` 子工程为唯一实现依据。
