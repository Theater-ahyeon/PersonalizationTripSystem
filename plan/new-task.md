## P0 — 阻塞性 Bug

### T1 数据集切换（已完成）
- **描述:** 清华数据集无法正常切换
- **位置:** `app.js` / 数据加载入口
- **预期:** 切换数据集后地图 & 数据面板同步刷新，无白屏/报错
- **验收:** 点选不同数据集后地图重新渲染、路网正确

### T2 路线策略无区分度（只显示了时间，但是策略还是相同的）
- **描述:** 无论选哪种策略（最短/最快/推荐）结果都一样，且未标注耗时
- **位置:** 后端 PathPlanner / 前端路线渲染
- **验收:**
  - 不同策略输出不同路线
  - 每条路线旁显示预估时间
  - 前端下拉/按钮选择后即重算

## P1 — 功能缺失

### T3 AIGC 动效展示（已完成）
- **描述:** 调用 API 后仅生成文字，无动画/可视化
- **位置:** 前端 AIGC 结果显示区域
- **验收:** 调用后在地图/画布上能看到动态效果（如路径绘制动画、节点闪烁），而非纯文本

### T4 室内导航可视化（完成了基础的模板，但还是简陋，后续可进行优化）
- **描述:** 后端可计算室内导航，前端只显示文字，未在地图渲染
- **位置:** `app.js` 室内导航渲染逻辑
- **状态:** 待技术验证（是否在 Leaflet 上叠加室内层）
- **验收:** 可行则落地，不可行则文档说明原因并关闭

### T5 地图节点搜索（已完成）
- **描述:** 搜索框输入后无实际跳转/高亮
- **位置:** `app.js` 搜索事件绑定 / SearchService 接口
- **验收:** 输入节点名 → 地图定位+弹窗/高亮

## P2 — UI/UX 优化

### T6 日记模块布局错乱（已完成）
- **描述:** 日记卡片一行三个 vs 一行两个，不一致
- **位置:** web 前端日记页面 CSS Grid / Flex
- **验收:** 所有卡片等宽等高，固定列数（如 3 列），无空位

### T7 图片统一&对齐（未完成）

- **位置:** `web/` 图片资源 + CSS `object-fit`
- **验收:**
  - 所有卡片图片使用实际内容图（非占位）
  - `object-fit: cover` 保持比例一致
