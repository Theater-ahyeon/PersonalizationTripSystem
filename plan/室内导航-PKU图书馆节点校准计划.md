# 室内导航校准计划：北京大学图书馆节点坐标修正

## 1. 问题描述

### 现状
北京大学图书馆 (`pku_library`) 是目前室内导航中唯一拥有**真实楼层平面图**的建筑（4层楼分别从北大图书馆官网获取），但导航节点坐标与平面图实际布局严重不匹配。

### 原因
当前 `web/scripts/core.js` 中 `pku_library` 的节点坐标（`x, y` 百分比值）是凭感觉估算的，没有对照平面图逐一标注。例如：

```js
// 当前代码（core.js 约第284-317行）
{ id: "pku_1_east", name: "东门入口", floor: "1F", x: 84, y: 74 },
{ id: "pku_1_info", name: "咨询台", floor: "1F", x: 74, y: 70 },
```

这些坐标与图片上"东门入口"的实际位置不一致，导致：
- 规划的路径显示在错误的位置
- 节点标注叠在错误的房间上
- "大门→电梯→房间"的导航动线与实际不符

### 目标
将 4 层楼共 33 个节点的 `(x, y)` 百分比坐标修正为与实际平面图位置一一对应。

- 支持鼠标/触屏拖拽节点到正确位置
- 实时显示 `(x, y)` 百分比坐标
- 提供"吸附到5%网格"功能方便对齐

## 3. 执行步骤

### 步骤1：启动校准工具
```bash
# 从项目根目录
python -m http.server 5173 --directory plan
# 浏览器打开 http://localhost:5173/calibrate_pku_library.html
```

或者直接双击 HTML 文件在浏览器中打开（图片使用相对路径）。

### 步骤2：逐层校准坐标

每层操作流程相同：

| 动作 | 说明 |
|:----|:------|
| ① 选择楼层 | 从下拉框选 1F / 2F / 3F / 4F |
| ② 观察图片布局 | 查看平面图上的房间名称和位置标注 |
| ③ 拖拽节点 | 每个彩色圆点拖到平面图上对应位置 |
| ④ 坐标显示 | 底部 `status-bar` 实时显示当前拖拽节点的百分比坐标 |
| ⑤ 可选：吸附网格 | 点"吸附到5%网格"按钮将坐标归整到 5% 整数倍 |
| ⑥ 切换下一层 | 重复①~⑤ |

#### 节点位置指引（按平面图实际布局）

**1F（一层）** — 由东向西：
```
[东门入口] → [咨询台] → [总服务台] → [自助借还区] → [证卡服务]
                                                  ↓（向南）
                              [目录检索区] → [报刊阅览区] ← 西
                              [目录检索区] → [展览厅]     ← 东
                              [目录检索区] → [一层电梯/楼梯] ← 中轴线
                                            [西侧学习区]
```

| 节点 | 图片上的位置参考 |
|:-----|:---------------|
| `东门入口` | 平面图最右侧（东侧）入口位置 |
| `咨询台` | 进门后的左侧服务台 |
| `总服务台` | 中部的圆形/方形服务台区域 |
| `自助借还区` | 总服务台旁边 |
| `证卡服务` | 西侧服务窗口 |
| `目录检索区` | 中轴线偏下区域的电脑检索区 |
| `报刊阅览区` | 西侧（左侧）的阅览区域 |
| `展览厅` | 东侧（右侧）的展览区域 |
| `一层电梯/楼梯` | 平面图中部的楼梯/电梯图标位置 |
| `西侧学习区` | 最西侧的学习座位区 |

**2F~4F（二至四层）** — 类似布局：
```
[电梯/楼梯] ← 中轴线
   ↓
[阅览区A] ——— [阅览区B] ← 上部区域
   ↓
[阅览区C] ——— [阅览区D] ——— [阅览区E] ← 中部区域
   ↓
[自助区 / 学习座] ← 下部区域
```

| 节点 | 图片上的位置参考 |
|:-----|:---------------|
| `{n}层电梯/楼梯` | 每层平面图中部的楼梯/电梯图标 |
| `自然科学阅览区(2F)` | 2F 电梯左侧的阅览区 |
| `社会科学阅览区(2F)` | 2F 电梯右侧的阅览区 |
| 其他阅览区 | 按图片中对应的实际位置放置 |
| `自助复印区` / `学习座` | 每层底部的服务区/座位区 |

### 步骤3：生成修正代码

所有楼层调整完毕后：

2. 工具输出完整的 `nodes` 数组 JSON（格式与 `core.js` 完全一致）
3. 点击 **"复制到剪贴板"** 按钮

- ✅ "大门→电梯→房间"三段式导航的节点名称合理
- ✅ 楼层切换时电梯节点位置一致（所有楼层的电梯在相同百分比坐标）

## 4. 如果无法手动拖拽（纯代码方案）

如果无法使用可视化工具（比如远程环境无浏览器），可以用以下**经验公式**估算坐标：

### 4.1 坐标系约定
北大图书馆平面图布局基本对称：
- **`x` 从左到右**：0 = 最西侧，100 = 最东侧
- **`y` 从上到下**：0 = 最北侧（顶部），100 = 最南侧（底部）

### 4.2 各区域估算规则

```
电梯/楼梯位置：x ≈ 50（中轴线），y ≈ 30（上部区域入口）
东侧入口（1F）：x ≈ 85~90，y ≈ 70~75（右侧中间偏下）
西侧区域：   x ≈ 20~35
中部区域：   x ≈ 40~60
东侧区域：   x ≈ 65~80

每层布局模式：
  ┌──────────────────┐
  │  电梯/楼梯(x≈50)  │  ← y≈30
  │  ┌────┐  ┌────┐  │
  │  │阅览A│  │阅览B│  │  ← y≈40~45
  │  └────┘  └────┘  │
  │  ┌────┐  ┌────┐  │
  │  │阅览C│  │阅览D│  │  ← y≈55~60
  │  └────┘  └────┘  │
  │   [自助区/学习座]   │  ← y≈73~78
  └──────────────────┘
```

### 4.3 各层统一修正值

| 节点 | 建议 x | 建议 y | 说明 |
|:-----|:------:|:------:|:----|
| `{n}_lift` | 50 | 28 | 电梯在所有楼层同一位置 |
| `{n}_science/literature/rare` | 35 | 39 | 左侧上部阅览区 |
| `{n}_social/history/periodical` | 65 | 39 | 右侧上部阅览区 |
| `{n}_philosophy/foreign/local` | 28 | 58 | 左侧中部阅览区 |
| `{n}_language/reference/special` | 52 | 58 | 中部阅览区 |
| `{n}_art/group/microfilm` | 73 | 58 | 右侧中部阅览区 |
| `{n}_self/quiet/reading` | 48 | 77 | 底部自习/服务区 |
| `{n}_east` | 78 | 74 | 东侧座位区 |

### 4.4 执行纯代码修正

如果走纯代码路径，直接修改 `web/scripts/core.js`：

**定位**：`pku_library` 对象的 `nodes: [ ... ]` 数组（约第 284~317 行）

**替换**：将整个 `nodes` 数组替换为以上建议坐标，然后重启前端查看效果。如果位置仍有偏差，微调个别节点的 `x, y` 值（+/- 3~5 个百分点）并刷新页面即可快速迭代。
