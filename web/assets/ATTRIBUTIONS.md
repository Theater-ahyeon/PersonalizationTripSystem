# Image Attributions

Images in `web/assets/spots/real/` are used for the local course demo. SVG icons in `web/assets/spots/` are project-local illustrative assets.

## Map Data

- Summer Palace and Tsinghua University POI anchors, route transition nodes, and road edges in `cpp/data/` and `web/data/` are derived from OpenStreetMap data fetched through Overpass API and the OpenStreetMap map API on 2026-06-04. Data (c) OpenStreetMap contributors, available under the Open Database License (ODbL): https://www.openstreetmap.org/copyright.
