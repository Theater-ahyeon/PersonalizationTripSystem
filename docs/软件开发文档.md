# 个性化旅游系统（TripSystem）软件开发文档

## 1. 开发任务

本项目面向景区游览场景，实现一个可演示的个性化旅游系统。当前演示场景为 **北京颐和园 + 周边服务区**。

系统采用“C++ CLI 算法主体 + 静态前端演示层”的结构：

- C++17 负责数据加载、手写数据结构、推荐、路径、搜索、日记压缩和美食推荐。
- `web/` 前端负责读取同一批 JSON 数据，用地图和功能面板展示课程验收入口。
- 不使用数据库，不接大型后端 API，数据通过 JSON 和日记 `.bin` 文件持久化。

## 2. 功能需求

- 旅游推荐：根据用户兴趣、评分、热度生成 Top-10 推荐，并支持分类/关键词筛选。
- 旅游路线规划：支持单目标最短路径、多目标游览顺序和地图路线高亮。
- 场所查询：查询卫生间、游客服务、商店、地铁站、观景台等设施，并按路径距离排序。
- 旅游日记：展示日记列表，按热度、评分、兴趣匹配排序，支持关键词检索和压缩率展示。
- 美食推荐：按当前景点、菜系、评分、热度、路径距离推荐餐饮。
- 数据概览：前端直接展示节点、边、景点建筑、服务设施、用户和日记规模。

## 3. 技术方案

- 语言：C++17、HTML、CSS、JavaScript。
- 地图：Leaflet + OpenStreetMap 瓦片，本地保留 Leaflet 文件和离线占位瓦片。
- 数据：`cpp/data/*.json`、`cpp/data/diaries/*.bin`。
- 生成脚本：`web/scripts/generate-osm-data.mjs` 使用 Overpass 拉取颐和园真实道路节点。
- 验证脚本：`web/scripts/smoke.ps1`、`cpp/scripts/smoke.ps1`。

## 4. 核心数据结构与算法

| 模块 | 数据结构/算法 | 作用 |
| --- | --- | --- |
| 推荐 | MinHeap、Top-K | 保留评分/热度/兴趣综合分最高的推荐项 |
| 路线 | 邻接表图、Dijkstra、A* | 景点最短路和 OSM 路网路径 |
| 多点游览 | TSP 状态压缩 DP | 规划多个目标点的访问顺序 |
| 查询 | Trie、KMP、HashMap | 前缀补全、关键词匹配和去重 |
| 日记 | Huffman | 日记正文压缩存储和解压浏览 |

## 5. 数据文件

- `spots.json`：`id/name/category/rating/heat/tags`，当前 24 条。
- `roads.json`：`from/to/dist_walk/dist_bike`，用于 C++ 景点图路径。
- `osm_nodes.json`：`id/name/lat/lon/type/spot_id/description/image`，当前 228 条，坐标均位于颐和园 bbox 内。
- `osm_edges.json`：`from/to/distance/mode/road_name`，当前 526 条有向边。
- `restaurants.json`：`id/name/near_spot_id/cuisine/rating/heat`，当前 50 条。
- `facilities.json`：前端场所查询数据，当前 60 条、12 类设施。
- `users.json`：前端个性化用户画像，当前 10 个用户。
- `diaries/index.json`：前端日记交流索引，当前 12 条。
- `diaries/{id}.json` + `diaries/{id}.bin`：C++ Huffman 日记元数据和压缩正文。

## 6. 前端验收界面

`web/index.html` 提供六个视图：

1. 推荐：展示旅游推荐排序算法。
2. 路线：展示默认“颐和园东宫门 → 苏州街入口”路径高亮和多点游览。
3. 查询：展示服务设施按路径距离排序。
4. 日记：展示热度、评分、兴趣匹配和压缩率。
5. 美食：展示菜系、评分、热度、距离综合推荐。
6. 数据：展示课程数据规模是否满足要求。

启动方式：

```powershell
python -m http.server 5173
```

访问：

```text
http://localhost:5173/web/index.html
```

## 7. 测试与验收

```powershell
powershell -ExecutionPolicy Bypass -File .\web\scripts\smoke.ps1
powershell -ExecutionPolicy Bypass -File .\cpp\scripts\smoke.ps1
```

前端 smoke 校验：北京 bbox、节点数、边数、景点建筑数、服务设施数、餐饮数、用户数、日记数、图片路径、关键函数和默认路径可达性。

C++ smoke 校验：构建、景点最短路径、OSM A*、多点游览、推荐、搜索、日记和美食推荐入口。
